何を見ればいいか

one-flow lab では「上の波形」と「下の関係グラフ」をセットで見ます。

events
0/whiteから差が立ち、観測可能な出来事になった数。
chain
因果的な深さ。時間・旋律っぽさ。
width
同時面・空間幅っぽさ。
avg degree / r
関係の濃さ。濃すぎると毛玉、薄すぎると断片。

この実験の目的

0/white から差が立ち、その差が event になり、event同士の依存から relation と causal order を読み、最後に geometry hint を測ります。

claim discipline：これは宇宙生成の主張ではなく、根本原理に近づくための toy model です。
