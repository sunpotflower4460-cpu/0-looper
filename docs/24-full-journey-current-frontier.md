## 今回の重要訂正

### 1. スケール完全ゲージは未確定

正しい：

```text
等価原理 = 一様な gravitational field はゲージ
```

まだ未確定：

```text
scale itself is gauge
```

標準 GR は scale `G` を持つ。  
scale 完全ゲージは conformal gravity / scale-invariant program の frontier。

### 2. 3D ball growth の d≈2.56 は 3Dそのものではない

手で作った cubic lattice は構成上 3D。  
小さい L では有限サイズと境界で slope が抑えられる。  
L を増やすと 3 に近づく。

したがって、3D ball growth は創発ではなく測定器の較正。
