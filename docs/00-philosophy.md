# 00 — Philosophy

## 0 は無ではない

このプロジェクトでは、0 を「何も無い」とは扱わない。  
0 は、状態空間の中で差がまだ立っていない基底状態である。

- 無：状態空間も、ルールも、関係も、時間もない
- 0：値として存在するが、差がまだ立っていない
- 白：未分化の存在。分光される前の全体
- 差：白の中に偏り・位相・関係が立つこと

この区別が大事。  
無からは何も始まれない。  
しかし 0 からは、ルール・ゆらぎ・不安定性があれば差が立つ。

## 白は空間ではなく存在

白を「空間」と見なすと、最初から器を置いてしまう。  
この repo では、白をより根本のもの、つまり「未分化の存在」として扱う。

空間は、最初からある箱ではなく、関係が安定して読めるようになった方向かもしれない。  
その仮説を、いきなり宇宙として主張せず、toy model で小さく測る。

## プリズムとしてのルール

白色光は無ではない。  
複数の波長が未分化に重なっている。  
プリズムを通ると、それが色として分かれる。

0-looper では、ルールをプリズムとして扱う。

```text
white / 0     = 未分化の基底
rule          = プリズム
noise         = 最初の微差
instability   = 微差を育てる条件
modes         = 分光された色 / 波長 / 構造
```

## 無音から音楽へ

無音は「何も無い」ではない。  
DAW の無音トラックは、タイムライン・サンプルレート・再生エンジンを持つ。  
音はまだ鳴っていないが、音楽は始まりうる。

音楽が始まると、複数の楽器は別々の波でありながら、マスターでは一つの合成波形になる。

```text
各楽器       = 部分モード
ミックス全体 = 合成波形
マスター処理 = 全体場への作用
```

これは、AeternaGenesis の場の見方と対応する。  
部分は部分としてあり、同時に全体として一つの波でもある。

## Claim discipline

このプロジェクトでは、詩的直感と測定を混ぜない。

- measured：このコードで直接測ったこと
- observed：表示上の観察
- interpretive：既存の物理概念への読み替え
- analogy：音楽・神聖幾何学・生命への比喩
- frontier：まだ未検証の前線

中心の規律：

> 描かずに、生まれたものを測る。
