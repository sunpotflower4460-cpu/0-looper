# 02 — Relation-first universe hypothesis

## 中心仮説

0-looper の中心は、空間を最初に置くことではない。  
最初に置くのは、**未分化の存在 0 / white** と、そこに差を立てる **関係のルール** である。

仮説：

> 空間は先にある箱ではなく、関係と因果順序が十分に安定したとき、後から読める幾何である。

ここで「宇宙そのものと同じ原理」を目指すとは、宇宙を再現したと主張することではない。  
現実宇宙にも必要だと思われる、より根の条件を toy model に落とすという意味である。

## 最小条件

### 1. 0 は無ではない

0 は空集合ではなく、差がまだ立っていない基底状態。  
ここにルールがなければ何も始まらない。  
しかしルールとゆらぎがあれば、差は立ちうる。

### 2. 差が event になる

場や関係網の中で、変化が閾値を超えた場所を event と呼ぶ。  
event は「点」ではなく、「区別が立ったこと」。

### 3. 関係が event を結ぶ

event 同士に依存があるとき、関係を張る。  
関係は距離ではない。  
距離は、関係網が安定したあとに読む。

### 4. 関係に向きがあると因果になる

A が B の発生条件に含まれるなら、A → B。  
この向きが因果順序である。

### 5. 因果順序から時間が読める

最長の因果鎖は、toy model では固有時のような量として読む。  
これは厳密な時空ではなく、順序が時間的な深さを持つかを見る測定である。

### 6. 関係網から空間が読めるかを測る

空間座標を使わず、次を見る。

- 有界次数：全員が全員とつながらないか
- 局所性：近い関係が安定して残るか
- クラスタ：近傍同士がまとまりを持つか
- antichain：同時面のような幅があるか
- comparable ratio：ほぼ全順序や完全ランダムに潰れていないか
- longest chain scaling：event 数に対して鎖長がどう伸びるか

## 重要な失敗条件

### all-to-all collapse

全 event がほぼ全 event と関係してしまう場合、距離が消える。  
これは空間ではなく、ただの絡まった毛玉である。

### chain collapse

event がほぼ一直線の鎖になる場合、幅が消える。  
これは空間ではなく、ほぼ 1 次元の時間列である。

### frozen zero

0 がずっと 0 のままなら、差が立っていない。  
これは無ではないが、まだ世界になっていない。

## 宇宙条件への近づけ方

現実宇宙を再現するのではなく、以下の条件を「宇宙的に必要そうな制約」として試す。

1. **no preferred coordinate**：力学に座標を使わない。表示用の位置は後付け。
2. **causal order**：関係には過去→未来の向きがある。
3. **bounded influence**：一つの event が直接影響できる範囲を制限する。
4. **local closure**：近い関係だけが閉じて局所性を作る。
5. **balance / bookkeeping**：符号や量が一方に発散しない。
6. **growth without drawing target**：空間・トーラス・生命を直接描かない。
7. **observable geometry**：後から測ると、距離・次元・層が読めるかを見る。

## 0-looper での実行方針

`relation-lab.html` では、固定格子を使わず、event と relation の成長だけを走らせる。

- event は順番に生まれる
- parent event から child event へ causal edge を張る
- child の parent は、座標距離ではなく、関係上の compatibility と frontier から選ぶ
- 可視化の座標は force layout で後から置くだけで、力学には使わない
- longest chain / width / comparable ratio / degree / clustering を測る

目的は、次を確認すること。

> 関係と因果だけで、空間らしい幅と局所性が読める条件はあるか。

## claim discipline

言ってよいこと：

> 関係と因果順序から、幾何らしさを読む toy model を作った。

まだ言わないこと：

> 宇宙を作った。  
> 重力を導いた。  
> 時空を無から生成した。  
> 現実宇宙と同じモデルである。

この repo の態度：

> 宇宙を描かず、宇宙に必要そうな根の条件を小さく測る。
