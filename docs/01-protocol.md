# 01 — Protocol

## P0: 0-looper toy

### 問い

0 を「無」ではなく「未分化の存在基底」と見たとき、局所ルールとゆらぎだけから何が読めるか。

### 入れるもの

- 固定された 1D 周期リング
- 実数場 `u[i]`
- 0 初期状態
- 微小ノイズ
- 局所ルール

```text
du = D * laplacian(u) + mu * u - u^3 + eta * noise
```

### 入れないもの

- 生命
- 意識
- トーラス
- 重力
- 宇宙
- 神聖幾何学の初期配置
- 空間そのものの創発という主張

## 観測するもの

### 差

`mean |u|` が 0 から離れるか。

### event

場が閾値を超えた場所、または局所的に大きく変化した場所。

### cause

ある event が、その直前の近傍 event に依存していると読める場合、cause として数える。

これは本物の因果集合論ではない。  
ただし、変化の依存方向を event graph として読む練習になる。

### longest chain

cause 関係をたどった最長系列。  
音楽で言えば、点ではなくフレーズ。

### d hint

簡易指標：

```text
d_hint = log(event_count) / log(longest_chain)
```

これは厳密な次元推定ではない。  
本格検証では、複数サイズ N と複数 seed でスケーリングを取る。

## 次の検証案

1. N を 64, 128, 256, 512 に変えて longest_chain のスケーリングを見る
2. 1D 固定格子、2D 固定格子で「空間次元 + 1」が読めるか検証する
3. 関係グラフのみから、固定格子を使わず距離が読めるか試す
4. Gray-Scott の spot birth/death/split を event 化する
5. event lineage を因果グラフとして出力する

## 重要な線引き

この repo の最初の実験は、空間そのものを作っていない。  
近傍関係は固定リングとして最初から与えている。

したがって、現段階で言えるのは：

> 0 状態 + 変化のルールから、差・event・依存順序を読む toy model を作った。

まだ言わないこと：

> 空間を無から作った。  
> 重力を導いた。  
> 生命を作った。  
> 宇宙の起源を再現した。
